ホワイトペーパーを書くうえでの注意

1. Github Issuesをグラウンドトゥルースに。新しい情報を仕入れた場合はすべてgithub issueにアップデート。
2. 並列作業。できるだけたくさんsectionsごとにエージェントを起動して作業する。
3. 読者はプロフェッショナルであっても一方で分かりやすや読みやすさや図表を忘れない。
4. 鳥の目と虫の目。分かりやすくオーバービューを説明するのと、たとえ論文を読まなくてもいいように分かりやすくリマーカブルな論文を説明。
5. 全てに引用を。reference.bibをアップデートしてできるだけ引用を与える。

リサーチして章を分厚くする具体手順（並列エージェント方式）は
`skills/deepen-whitepaper/SKILL.md` に定式化してある。加筆・更新を頼まれたらまず読むこと。
